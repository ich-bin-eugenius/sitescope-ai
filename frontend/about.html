About Project

Why I built SiteScope AI

SiteScope AI started as a simple idea: make website audits easier to understand.

Website audits can produce a lot of technical data, but not everyone knows what all those numbers and warnings actually mean. SiteScope AI takes this data and turns it into clear explanations, why each issue matters, and practical suggestions for fixing it.

The project combines Google PageSpeed Insights, FastAPI and Gemini AI to create an automated website analysis pipeline.

I'm building SiteScope AI as an open-source project and using it to learn more about web development, APIs, AI, backend development and real-world software engineering.

This project is still evolving, and there is a lot more I want to add.
